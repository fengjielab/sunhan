\section{Conclusion}
This paper presents a vision-semantic, event-triggered multi-channel joint parameter-configuration framework for pre-contact parameter preparation in haptic teleoperation of heterogeneous objects. A three-level mapping from object semantics to an operational strategy and then to a joint parameter set aims to make slave-side impedance, the master-side haptic interface, and gripper execution available as a unified strategy-level bundle before interaction. An asynchronous one-shot update integrates this configuration after task initiation while keeping low-rate perception outside the synchronous supervisory path. By avoiding complex online optimization, the framework provides interpretable and deployable system-level parameter configuration with a relatively low online computational burden.

In 135 physical trials involving three operators, six objects, and five modes, the full cross-channel mode C achieved the shortest completion time, the highest observed success rate, and the lowest Raw NASA-TLX score. Relative to mode E, which used the same semantic mapping and impedance settings, mode C reduced mean completion time by 1.79 s, with a matched-task-block bootstrap 95\% CI of [1.10, 2.51] s. The direction of the C--E difference favored mode C for each operator and object. No clear difference was observed in master-side trajectory length, indicating that the time advantage could not be explained solely by path shortening.

Under the present heterogeneous-object teleoperation conditions, the complete configuration produced better task-level performance than either impedance-only scheduling or the default visual-semantic cue with fixed parameters. The experiments provide system-level evidence for the overall effect of the complete parameter bundle on the current platform, while the causal contribution of each channel remains unresolved.

Looking ahead, this work will extend early-stage parameter preparation toward closed-loop multi-channel configuration throughout the manipulation process. First, synchronized records of visual strategy events, initial contact, external-force estimates, gripper states, and task outcomes will be added to quantify the temporal relationship between semantic triggering, contact establishment, and task performance. Second, post-contact feedback, including interaction force, slip risk, and grasp state, will be used to verify and, when needed, correct the parameter bundle selected by the strategy event. This will advance the system from one-shot preparation to a ``pre-contact prediction--in-contact verification--post-contact adjustment'' loop. Finally, strategy learning, parameter-sensitivity analysis, and operator-specific adaptation will be studied across broader object classes and task conditions to improve generalizability and long-term deployability.
