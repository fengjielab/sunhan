# 离线视觉鲁棒性测试：操作说明

本程序只读取 RealSense 彩色相机并运行 YOLO，不连接、不控制机械臂。

## 1. 实验前准备

准备以下物品：

- 原实验使用的香蕉 A、瓶子 A、剪刀 A；
- 另外一根外观不同的香蕉 B、另一个瓶子 B、另一把剪刀 B；
- 未知物体：订书机、螺丝刀、卷尺、小纸盒、海绵；
- 固定杂物：钥匙、胶带卷、直尺；
- 一张不反光的灰色或黑色遮挡卡；
- 一盏可移动台灯；
- 胶带，用于在桌面标记一个 15 cm × 15 cm 的中央目标区。

相机位置、角度和目标区位置必须与论文的人机实验保持一致。整个采集期间不能移动相机。机械臂应关闭或保持静止。

在中央目标区内再标出5个小点。程序中的重复编号对应：

- R01：中心点；
- R02：中心左侧 3 cm；
- R03：中心右侧 3 cm；
- R04：中心向相机方向 3 cm；
- R05：中心远离相机方向 3 cm。

未知物体只有 R01–R03，分别使用中心、左移 3 cm、右移 3 cm。每种物体的基本姿态沿用原人机实验的抓取姿态，在同一组5次中不要改变朝向。

## 2. 复制并运行

将整个 `vision_robustness` 文件夹复制到实验用 Ubuntu 电脑，然后运行：

```bash
cd /你的实际路径/vision_robustness
python3 offline_vision_capture.py --make-manifest-only
```

确认生成 `scene_manifest.csv`，其中应有 120 行实验任务。第一次只采集正常场景的15轮：

```bash
python3 offline_vision_capture.py \
  --model /home/mfj/sunhan/yolo/ultralytics-8.3.163/yolo11n.pt \
  --output /home/mfj/sunhan/vision_robustness_data \
  --condition normal \
  --group-by-object
```

`--group-by-object` 表示“同类连续录制”：同一光照下先连续录完同一物体（如
香蕉的 5 个位置），再换下一个物体；换物体时程序会打印 `▸ 本组物体：…`
提示。同类内部的 R01–R05 顺序仍与 `scene_manifest.csv` 相同（原实验的随机
顺序），只是不同物体不再互相穿插。如确要按清单里穿插的原顺序录制，去掉
`--group-by-object` 即可。

正常组15轮完成后程序会自动结束。程序会自动从该条件（下一个未完成的物体组）
第一条未完成任务继续，因此可以随时按 `Q` 停止，下一次执行同一命令即可续采。

后续弱光组使用同样的命令，只需把最后两行改为：

```bash
  --condition dim \
  --group-by-object
```

## 3. 每一轮怎么操作

1. 查看终端显示的 `Episode` 和摆放说明。
2. 按照提示摆放物体。
3. 等待约 2 秒，让相机自动曝光稳定。
4. 按空格开始录像。
5. 录像自动持续 10 秒，期间不要移动物体、相机或灯。
6. 结束后输入 `Y` 接受；摆错了输入 `R` 重做。
7. 每轮结束后先把所有物体拿出画面，再布置下一轮。

录制中按 `X` 或 `Esc` 会取消当前轮，不写入正式汇总。

## 4. 各条件的实物摆放

### normal

目标物单独放在中央方框中，正面朝相机，使用原实验正常光照。

### dim

目标物位置不变。关闭主灯或降低照明，使物体表面约为 50–100 lux。没有照度计时可以使用同一部手机的照度计应用，但全文应表述为近似照度。

### backlight

目标物位置不变。把台灯放在物体后方约 30–50 cm，灯大致朝向相机，使物体形成明显背光，但不要让灯或灯架遮挡物体。

### occlusion50

目标物位置不变。用不反光遮挡卡挡住目标可见轮廓约一半。奇数重复遮左侧，偶数重复遮右侧。

### clutter

目标物仍位于中央方框。把钥匙、胶带卷和直尺放在方框外，分别位于目标的左、右和后方，不要遮挡目标。120轮中始终使用同一组三件杂物。

### multiobject

目标物在中央方框，另一个已映射物体放在目标左侧或右侧 12–15 cm，深度与目标相同：

- 香蕉为目标时，旁边放瓶子；
- 瓶子为目标时，旁边放剪刀；
- 剪刀为目标时，旁边放香蕉；
- 奇数重复放左侧，偶数重复放右侧。

### new_instance

只放一个物体，但必须使用同一语义类别的另一件实物 B。例如香蕉 B 仍然必须是真香蕉，不能用苹果代替。

### unknown

每次只将提示的未知物体放在中央方框：订书机、螺丝刀、卷尺、小纸盒或海绵。未知物体被错误识别成已映射类别也是有效实验结果，不要因此重做。

## 5. 什么情况下需要重做

仅在以下操作错误时重做：

- 放错目标物或干扰物；
- 遮挡比例明显错误；
- 录像期间有人手进入画面；
- 相机、灯或物体意外移动；
- 程序或相机报错。

识别错误、没有检测到物体或置信度低都是真实结果，不能因为结果不好而重做。

## 6. 输出文件

输出目录包括：

- `episode_summary.csv`：每轮的主要结果；
- `videos/`：每轮原始 RGB 视频；
- `detections/`：逐帧全部检测框和置信度；
- `run_config.json`：模型哈希、阈值、分辨率和帧率；
- `scene_manifest_snapshot.csv`：本次实验使用的任务清单副本。

第一天不要直接做完120轮。先完成 normal 条件的15轮，然后把整个输出目录复制回来检查；确认日志、视频和任务编号都正确后，再继续弱光等条件。
