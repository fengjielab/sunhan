\section{Conclusion}
This study presented an object-conditioned strategy-level multi-channel parameter-configuration framework for haptic teleoperation of heterogeneous objects. Each detected object class was mapped to one of three interpretable manipulation strategies, which jointly specified the slave-side impedance, master-side haptic feedback, and gripper-execution parameters. Low-rate visual perception was integrated asynchronously with the nominal 200-Hz supervisory loop through a one-shot strategy event, and the selected strategy remained locked for the remainder of the trial.

Across 27 matched task blocks comprising 135 physical trials, complete multi-channel configuration yielded a 1.79-s lower mean task completion time than impedance-only reconfiguration, corresponding to an 8.5\% reduction (matched-block bootstrap 95\% CI, 1.10--2.51 s). The mean C--E completion-time difference favored complete multi-channel configuration for all three operators and all six tested objects. This mode also showed the highest observed success rate and the lowest median Raw NASA-TLX score; both outcomes were interpreted descriptively. The C--E confidence interval for master-side trajectory length included zero.

These findings support a within-sample system-level benefit of coordinating slave-side impedance, master-side haptic feedback, and gripper execution beyond impedance-only reconfiguration under the tested conditions. Because the master-side haptic and gripper-execution channels changed together, their individual contributions remain to be isolated. Overall, the framework provides an interpretable system-design approach to object-conditioned multi-channel configuration for semi-structured haptic teleoperation tasks.
