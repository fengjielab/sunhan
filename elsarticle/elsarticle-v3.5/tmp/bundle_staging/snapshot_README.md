# Mechatronics LaTeX manuscript

Open `main.tex` in VS Code; it is the only compilation entry point. Edit the numbered chapter files, `declarations.tex`, `references.bib`, or the figure PNG files as needed. In LaTeX Workshop, run the recipe `pdflatex -> bibtex -> pdflatex x2`.

Project files are intentionally flat for Editorial Manager submission. `supplementary.tex` is a separate editable supplementary document and `highlights.txt` is uploaded as a separate Highlights file. The current snapshot uses `fig1.jpg` for Fig. 1; `main.pdf` and `supplementary.pdf` are local verification outputs, not source files.

The local reproducibility bundle is maintained separately as `Mechatronics_v5_reproducibility_bundle`. It contains the de-identified data, analysis entry points, supplementary outcome tables, final figure assets, and available figure-source files. Before submission, deposit that exact bundle in a public repository, choose an appropriate license, and replace the prospective repository wording in `declarations.tex` with its persistent identifier (DOI or equivalent). Confirm that the ethics statement reflects the institution's actual determination and complete Elsevier's separate declaration-of-interest form.
