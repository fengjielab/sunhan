# Resubmission package gate

- [ ] Formal protocol is locked and ethics details are complete.
- [ ] All 384 scheduled rows are accounted for, including documented interruptions.
- [ ] Every formal run passes schema-v3 validation or has an audit explanation.
- [ ] Raw data hashes and an external backup are verified.
- [ ] Primary model and all prespecified sensitivity analyses are frozen.
- [ ] Response matrix has no unresolved data placeholders.
- [ ] Main manuscript and supplement compile without errors.
- [ ] Figures are readable at final column width.
- [ ] Anonymized data/code/model configuration are deposited publicly.
- [ ] Repository DOI/URL and ethics reference appear consistently in all documents.
- [ ] Final main PDF, supplement, highlights, response letter, title page and source
      archive are copied here only after independent verification.
