## 填写说明

每组实验包含 **3 种物体**（软/中/硬）× **4 种模式** × **9 组重复实验**，共 108 次实验（第一组~第九组）。

| 物体 | 说明 | 对应实验目录 |
|------|------|-------------|
| 🟢 **软物体** (soft) | 软/易变形 | `my_test/soft_date/` |
| 🟡 **中物体** (medium) | 中等硬度 | `my_test/medium_date/` |
| 🔴 **硬物体** (hard) | 硬/不易变形 | `my_test/hard_date/` |

| 模式 | 对应中文名 | 说明 |
|------|-----------|------|
| A. **default** | 固定增益 | 固定参数，无视觉辅助 |
| B. **soft_obj / medium_obj / hard_obj** | 选择模式 | 选择对应物体手感预设 |
| C. **vision** | 全自动 | YOLO视觉自动识别→切换手感 |
| D. **vision_observe** | 消融 | 视觉仅观察，不改参数 |

### 评分标准
- **成功率**: ✔️=成功 / ❌=失败（物体掉落/破损）
- **效率评分 (1-5)**: 1=很费力/慢, 3=一般, 5=轻松/快
- **操作负荷 (1-5)**: 1=很轻松, 3=中等, 5=很累
- **抓取品质 (1-5)**: 1=很差, 3=一般, 5=完美
