# Historical scripts not used by the current manuscript

`full_statistical_analysis.py`, `complete_checklist_analysis.py`,
`fix_csv_scan.py`, and `fix_csv_scan2.py` are preserved for provenance only.
They contain exploratory analyses, historical path assumptions, or conclusions
that do not match the current manuscript's evidence boundary.  In particular,
the current manuscript treats Raw NASA-TLX as descriptive and does not claim a
channel interaction or synergy mechanism.

Do not use these scripts to regenerate manuscript tables or conclusions.  Use
`../run_core_reproduction.py` and `bootstrap_ci_ce.py` for the verified core
results.
