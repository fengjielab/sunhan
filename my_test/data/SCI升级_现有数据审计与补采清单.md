# SCI 升级：现有数据审计与补采清单

> 审计日期：2026-07-01  
> 目标边界：本文只研究“接触前视觉语义多通道前馈 + 工程可靠性 + 人因效率”；不把接触后力反馈融合、连续刚度修正及接触过程指标作为主贡献。

## 1. 审计结论

现有数据足以支撑中文核心稿及 SCI 稿的**先导实验**，但还不足以直接支撑计划中的 SCI 完整主张。

现有主实验实际包含 108 个 trial，而不是当前主稿所写的 72 个 trial：

\[
3\text{ 类物体}\times4\text{ 种模式}\times9\text{ 组}=108\text{ 次}
\]

第 1–3 组、第 4–6 组和第 7–9 组分别对应操作者 1、2、3。每位操作者在每个“物体类别 × 模式”条件下有 3 次重复。

现有 108 次数据能够支持：

- 完成时间；
- 主端轨迹长度；
- 主端速度均值、标准差、方差和最大值（最大值受尖峰影响，只宜作质量检查）；
- 成功率；
- 三项自定义 1–5 分主观评价；
- 3 名操作者之间的结果趋势；
- soft、medium、hard 三种操作属性之间的结果趋势；
- 固定参数、人工选择、视觉自动和视觉仅观察四种模式的对比。

现有数据不能直接支持：

- 语义驱动的主从缩放、速度限制或输入滤波效果；
- “仅阻抗调节”与“多通道前馈”的消融结论；
- 视觉置信度、锁定时间、误触发率、回退率和人工覆盖率；
- 每类 3 个具体物体的跨实例泛化结论；
- NASA-TLX 六维结论；
- 人工选择模式的选择延迟和选择错误率；
- 可靠的接触力过程统计。

因此最稳妥的路线是：**保留现有 108 次数据作为基线/先导实验，补采一套专门面向 SCI 主张的数据，不把旧数据硬解释成新方法证据。**

## 2. 现有数据资产

### 2.1 主实验数据

| 数据项 | 当前数量 | 覆盖情况 | 可用性 |
|---|---:|---|---|
| 主实验 CSV | 108 | 3 类 × 4 模式 × 9 组 | 可用 |
| 主实验汇总 JSON | 108 | 与 CSV 一一对应 | 可用 |
| 额外力自适应 CSV/JSON | 1 | medium 类单次试验 | 只能调试，不能统计 |
| 操作者 | 3 | 每人对应连续 3 组 | 可做小样本人因趋势，不宜宣称广泛泛化 |
| 操作属性 | 3 | soft / medium / hard | 可用 |
| 具体物体 ID | 0 个被结构化记录 | 文件名和 JSON 中均无 object_id | 缺失 |
| 视觉验证图片 | 仓库内 0 幅 | 未发现原始图像/标注/逐图预测表 | 缺失 |

四种现有模式映射如下：

| 论文模式 | 文件记录名 | 含义 |
|---|---|---|
| A | `default` / `固定增益` | 固定参数 |
| B | `soft_obj` / `medium_obj` / `hard_obj` / `选择模式` | 人工选择预设 |
| C | `vision` / `全自动` | 视觉语义自动调参 |
| D | `vision_observe` / `消融` | 视觉显示但不调参 |

### 2.2 CSV 已记录字段

现有 108 次主实验的统一字段为：

```text
time,x,y,z,gripper_deg,button,K_trans,K_rot,damping_ratio,K_fb,deadband,scale
```

由这些字段可以离线重算：

- trial 完成时间；
- 三维主端轨迹长度；
- 速度序列及其均值、标准差；
- 在预先固定阈值后的停顿次数/停顿总时长；
- 在预先定义方向变化规则后的轨迹修正次数；
- 参数切换过程和最终参数；
- 夹钳开合轨迹。

注意：停顿次数和修正次数目前没有预注册定义，分析前必须先固定阈值和算法，不能看完结果后调阈值。

### 2.3 当前可复核结果

根据 108 个汇总 JSON，当前四模式总体结果为：

| 模式 | 平均完成时间/s | 总体成功率 | 说明 |
|---|---:|---:|---|
| A 固定参数 | 21.44 | 22/27（81.5%） | 基线 |
| B 人工选择 | 21.03 | 21/27（77.8%） | 人工预设基线 |
| C 视觉自动 | **19.31** | **26/27（96.3%）** | 现有方法 |
| D 视觉仅观察 | 20.94 | 24/27（88.9%） | 视觉显示消融 |

三名操作者中，C 模式的平均完成时间均为四种模式中最短。该结果可作为跨操作者一致性的初步证据。

### 2.4 主观数据现状

`实验评分表.md` 包含每个 trial 的：

- 成功/失败；
- 效率评分（1–5）；
- 操作负荷（1–5）；
- 抓取品质（1–5）。

这些是自定义 Likert 量表，不是 NASA-TLX。仓库虽然有 `record_nasa_tlx.py`，但没有发现 `nasa_tlx_data.json`，因此当前论文不能声称已完成 NASA-TLX 六维评价。

## 3. 数据质量与表述风险

### 3.1 72 次与 108 次口径冲突

当前中文核心主稿使用 72 次和一套 6 次重复统计；格式整理前备份及实际数据则使用 108 次和 9 次重复统计。SCI 稿应统一采用可追溯的 108 次口径，除非明确说明排除了哪些 trial 及排除理由。

### 3.2 物体实例证据不足

文稿称每类使用不同实物样本，但现有目录、CSV 和 JSON 只记录 soft/medium/hard 类别，没有记录苹果、海绵、水瓶、木块等具体 `object_id`。因此当前数据只能稳妥支持“跨三类操作属性”，不能强支持“每类多物体实例泛化”。

### 3.3 180 幅视觉验证无法复核

当前仓库未发现 180 幅原始图像、人工真值、逐图预测结果或混淆矩阵源数据。因此“180 幅、类别识别和属性触发均为 100%”目前属于缺少可审计证据的表述。若原数据在仓库外，应完整恢复；否则需要重新采集。

### 3.4 参数调度与计划中的新方法不一致

现有 trial 的 `scale` 基本固定为 3.00，不能证明语义驱动的运动缩放。现有数据也没有速度限制值、滤波系数或原始/滤波后双通道记录，因此不能证明速度限制和输入滤波的独立贡献。

### 3.5 视觉可靠性字段缺失

现有 CSV 没有逐帧检测类别、置信度、候选目标数、ROI 命中状态、锁定时刻、回退状态和人工覆盖事件。汇总 JSON 中少量新版字段只表明是否锁定，不能计算锁定时间和触发正确率。

### 3.6 力数据不属于本 SCI 主线

现有主实验没有外力列。唯一 `force_adaptive` trial 记录了 `F_ext_mag`，但只有一次。当前程序新版已经能够记录外力和融合状态，这些字段应留给 RAL 数据集，不应为了 SCI 前馈稿强行补成主创新。

## 4. SCI 稿必须补采的数据

### 4.1 第一优先级：建立可审计实验元数据

每个 trial 必须记录：

| 字段 | 示例 |
|---|---|
| `trial_id` | `P01_soft_sponge_A_r01` |
| `participant_id` | `P01` |
| `object_id` | `soft_sponge_01` |
| `property_class` | `soft` |
| `mode` | `A/B/C/D/E` |
| `repetition` | `1` |
| `mode_order` | 随机化后的顺序位置 |
| `success` | `0/1` |
| `failure_reason` | 滑落/超时/碰撞/识别错误等 |
| `start_time` / `end_time` | 精确时间戳 |

没有这些元数据，后续很难做重复测量统计和可复现实验审计。

### 4.2 第二优先级：视觉安全触发数据

逐帧或逐次检测至少记录：

- `detected_class`；
- `mapped_property`；
- `confidence`；
- `bbox` 与 `roi_hit`；
- `candidate_count`；
- `lock_event` 与 `lock_time_s`；
- `fallback_event` 及原因；
- `manual_override_event`；
- 最终调用的策略 ID。

独立视觉验证集至少应保存：

- 原始图片；
- 人工标注真值；
- 逐图预测 CSV；
- 类别级和属性级混淆矩阵；
- 置信度分布；
- 低置信度、遮挡、多目标和非训练实例场景。

不要只报告总体准确率，更不能只保留汇总百分比。

### 4.3 第三优先级：多通道前馈控制数据

若 SCI 主方法包含语义驱动的缩放、速度限制和输入滤波，应逐采样记录：

- `scale_cmd`；
- `velocity_limit_cmd`；
- `filter_alpha_cmd` 或截止频率；
- `raw_master_x/y/z`；
- `filtered_master_x/y/z`；
- `desired_slave_x/y/z`；
- 当前策略 ID 及策略切换时间。

只记录最终参数不够，因为无法验证切换是否发生、何时发生以及是否影响运动行为。

### 4.4 第四优先级：人因数据

建议每名操作者、每种模式完成一次 Raw NASA-TLX 六维评分，并保留：

- Mental Demand；
- Physical Demand；
- Temporal Demand；
- Performance；
- Effort；
- Frustration；
- 总分或均分；
- participant、mode 和填写时间。

人工选择模式还应单独记录：

- 从呈现目标到完成策略选择的时间；
- 选择是否正确；
- 是否修改选择；
- 选择次数。

### 4.5 第五优先级：跨实例与跨操作者覆盖

最低建议：

- 每类 3 个明确编号的物体，共 9 个物体；
- 至少 6 名操作者；若资源允许，优先 10–12 名；
- 每位操作者每个关键条件至少 2 次有效重复；
- 模式顺序使用平衡随机化或 Latin square；
- 正式实验前统一训练，并记录训练 trial，不混入正式数据。

3 名操作者可以作为先导研究，但对以人因改善为主证据的 SCI 稿偏弱。

## 5. 推荐实验模式与最小补采方案

### 5.1 完整方案

| 模式 | 设置 | 回答的问题 |
|---|---|---|
| A | 固定参数 | 固定策略基线 |
| B | 人工选择完整策略 | 自动语义是否减少人工选择成本 |
| C | 视觉显示但不调参 | 视觉提示本身是否有效 |
| D | 视觉仅调阻抗 | 单通道调节是否足够 |
| E | 视觉多通道前馈 | 所提完整方法是否有效 |

其中 E 调度阻抗、力反馈呈现参数、夹爪参数、主从缩放和速度限制；是否加入输入滤波，应由工程实现和预实验结果决定，不建议为了凑通道强行加入。

### 5.2 最小可行补采

若实验资源有限，优先采集 D 与 E，而不是重做所有旧模式：

1. 用新日志格式补采 D（视觉仅阻抗）和 E（视觉多通道前馈）；
2. 使用同一批操作者和同一批明确编号物体；
3. 同时补录 NASA-TLX、视觉锁定和策略触发数据；
4. 旧 A/B/C 数据只在统计设计允许且实验条件完全一致时合并，否则作为先导实验单独报告。

严格来说，若设备参数、软件版本、物体、操作者或实验流程已经变化，最稳妥的是五模式全部重采。跨批次直接比较会把“模式差异”和“采集批次差异”混在一起。

## 6. 建议优先执行顺序

1. **先改日志，不先采数据**：加入 participant、object、trial、mode order、视觉置信度/锁定、策略 ID、缩放/限速/滤波命令字段。
2. **做 10–20 次预实验**：确认所有字段非空、时间同步合理、失败原因可记录。
3. **恢复或重建独立视觉验证集**：先验证安全触发机制，再进入人因主实验。
4. **固定统计方案**：预先定义停顿、轨迹修正、成功、超时和排除标准。
5. **正式采集五模式数据**：随机化模式与物体顺序，完整记录版本号和参数表。
6. **最后写 SCI 结果段**：在数据出来前，摘要和结论只保留待填占位，不预写显著性或优势结论。

## 7. 与 RAL 数据的隔离规则

SCI 数据表和正文不把以下内容作为主指标：

- 接触后连续刚度修正；
- 视觉—外力融合模式；
- 初始接触 0.5 s 力冲量；
- \(F_{95}\)；
- 力增长率；
- 接触稳定时间；
- 六模式融合消融。

如果新版程序顺带记录外力，可以保存在原始日志中用于安全检查，但 SCI 主文不围绕这些指标建立贡献。RAL 应使用独立实验编号、独立模式定义和新增接触过程数据。

## 8. 当前可立即做、无需补采的分析

在正式补采前，可以先对现有 108 次数据完成：

- 统一 108 次口径并生成 trial-level 总表；
- 以 participant 为被试因素核对重复测量结构；
- 重算完成时间、路径长度和速度分布；
- 在预先定义阈值后计算停顿次数与停顿总时长；
- 评估模式顺序是否与日期/组号混杂；
- 核对评分表与每个 trial 的一一对应关系；
- 输出所有异常 trial 和排除理由清单；
- 将 72 次版本与 108 次版本的差异逐项消除。

这些工作能把旧数据整理成可信的先导数据集，但不能替代上述缺失字段和新模式的正式补采。
