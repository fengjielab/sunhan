# Mechatronics 中英文逐句核对报告（以英文稿为准）

## 结论先行

当前原中文稿 `论文_Mechatronics版_最终术语与图文一致性检查稿.md` **不能再作为英文投稿稿的逐句中文对应版本**。它与当前英文 LaTeX 稿在系统实现、统计结果、图表结构和投稿声明上均存在实质版本差异；其中有些差异会改变方法事实或证据强度。

工作区已有的 `Mechatronics_full_Chinese_translation_v9.md` 已与当前英文稿的**正文技术内容、数值和限定语总体对齐**，但声明页及图表结构仍残留旧版本内容（见“仍未对齐项”）。本次不覆盖任何已有文件；阅读正文时可将 v9 作为当前的**英文对齐中文版基础稿**，不能将其当作最终图文一致稿。下文的“对应中文版”行号均指该文件。

本轮结论不是“英文已经没有问题”。英文稿的核心论证已比原中文稿谨慎得多，但投稿前仍必须解决伦理与数据可用性两个阻断项；并且必须继续避免把系统级组合效应写成单一通道的因果效应。

## 我的总体看法

论文的真正贡献应稳定表述为：**在受控的六对象、三操作者、135 次物理试验范围内，使用一次性对象语义事件，同时配置从端阻抗、主端触觉接口和夹爪执行，较“相同视觉语义 + 仅阻抗调度”表现出更短的任务完成时间。** 这个系统级结论有清楚的 C–E 对照支撑。

最容易被审稿人质疑的并不是“有没有视觉识别”，而是结论是否越过证据边界。当前英文稿已正确限制了以下事项：视觉测试并非试验内触发正确性的证明；参数设计不是优化或材料损伤阈值；C–E 不能拆分触觉接口与夹爪的独立贡献；三名操作者支持样本内重复测量结论而非总体推断。中文版必须完整保留这些限制，不能为了读起来顺而删掉。

建议后续修改时优先加强“可复现与可投稿性”，而不是再扩展应用场景：补齐伦理书面决定、公开可复核数据/脚本、加入同步的触发—接触记录，并在下一轮实验做通道级消融。否则“pre-contact”“safety”“haptic benefit”等词都会比现有证据更强。

## 仍建议作者决定或补强的事项

1. **伦理与数据：** 在任何投稿版本中，用机构的书面认定替换伦理占位符；将去标识化试验数据、Raw NASA-TLX、分析与绘图脚本、补充表存入公共仓库并填入持久标识符。这是当前两个明确的投稿阻断项。v9 的声明页不能直接用于投稿。
2. **题目与贡献边界：** “Object-conditioned”在本文表示固定六类对象的手工“类别→策略”映射，不是对未知对象物性或策略的自动推断。摘要、结论与投稿信均应保留这一边界。
3. **C–E 的措辞：** 只能说完整参数包的系统级表现优于仅阻抗调度；不能说“触觉增益导致改善”或“夹爪力导致改善”。要作该结论，需分别移除死区、增益、夹爪速度和夹爪力的消融。
4. **B 模式：** B 与 C 的差异包括人工识别、选择和运动许可时机，且没有单独的选择时间戳。因此 B–C 是工作流比较，不是纯控制器比较。
5. **安全与实时：** 有界参数集和约 300 ms 平滑过渡不等于多通道人在环系统的稳定性/被动性证明；名义 200 Hz 与 5.07 ms 中位周期不等于硬实时保证。请避免扩展性宣传超过这些事实。
6. **结果呈现：** 成功率、失败类型、暂停和 NASA-TLX 都应继续标为描述性或探索性；一名研究者的实时判定且没有录像复评，限制了对滑移/可见损伤的客观性。
