# 视觉识别验证操作说明

验证对象为苹果、香蕉、水瓶、硬纸杯、鼠标和剪刀。每个对象采集30帧，建议采用3种明显不同的摆放姿态，每种姿态10帧；相机位置、背景、光照和目标距离应与正式抓取实验一致。每次画面只放置当前待测对象，并保证目标完整进入视野。

依次执行以下采集命令：

```bash
python3 my_test/validate_vision_recognition.py capture --object apple
python3 my_test/validate_vision_recognition.py capture --object banana
python3 my_test/validate_vision_recognition.py capture --object bottle
python3 my_test/validate_vision_recognition.py capture --object cup
python3 my_test/validate_vision_recognition.py capture --object mouse
python3 my_test/validate_vision_recognition.py capture --object scissors
```

每次按空格保存一帧，改变姿态后继续采集。完成180帧后运行：

```bash
python3 my_test/validate_vision_recognition.py evaluate \
  --dataset my_test/data/vision_validation \
  --model yolo/ultralytics-8.3.163/yolo11n.pt \
  --conf 0.25 --imgsz 640
```

结果保存在`my_test/data/vision_validation/results/`：

- `vision_validation_per_image.csv`：逐图预测和耗时；
- `vision_validation_summary.json`：逐对象及总体统计；
- `vision_validation_paper_table.md`：可直接整理进论文的结果表。

类别识别正确率要求预测COCO类别与目标类别完全一致；属性触发正确率只要求最终操作属性一致。两者应分开报告，因为错误类别也可能因默认回退或同属性映射而触发正确参数。
