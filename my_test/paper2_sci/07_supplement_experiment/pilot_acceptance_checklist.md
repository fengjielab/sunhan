# 8 次预试验收清单

参数一旦通过预试即冻结；正式实验中不得根据结果调参。每项均需填写“通过/不通过”和备注。

| 检查项 | 验收标准 | 结果 | 备注 |
|---|---|---|---|
| 文件完整性 | 每次均生成 CSV、events JSON、summary JSON |  |  |
| 条件身份 | 日志 condition_code 与顺序表一致，配置哈希一致 |  |  |
| 原始视觉 | raw_vision_class/label/confidence 有记录；不作为受控先验输入 |  |  |

## 决策规则

- 任一安全、边界、条件身份或文件完整性检查失败：停止正式实验，修复后重新完成全部 8 次预试。
- 仅“可区分性”不通过：先检查接触阈值和外力估计质量；任何参数调整均须形成新配置版本和哈希，再重做全部预试。
- 预试数据不进入正式统计。
