# Omega.7 → Franka 遥操作：原理、代码架构与当前问题

## 一、整体架构

```
┌──────────────┐     ┌──────────────┐     ┌───────────────────┐
│  Omega.7 手柄 │ ──> │  映射层      │ ──> │  Franka 机械臂     │
│  (力觉设备)   │     │  (核心逻辑)   │     │  (panda_py)      │
└──────────────┘     └──────────────┘     └───────────────────┘
       │                    │                      │
  dhd.getPosition()    目标位置 =           ctrl.set_control()
  dhd.getGripper...()  虚拟参考 + 偏移 * 缩放     │
  dhd.getButton()              │           gripper.grasp/move()
                        坐标方向修正
                        夹爪角度→开度
                        按钮→夹爪复位
```

## 二、代码逐段原理

### 第 1 段：Omega.7 连接

```python
dhd.open()                       # 打开设备（默认只打开平移设备）
dhd.getPosition(raw_pos)         # 读取手柄位置 xyz(米)
dhd.getGripperAngleDeg(angle)    # 读取夹爪角度(度)，文档说张开 ~-60°，捏合 ~0°
dhd.getButton(0)                 # 读取灰色按钮，0=未按 1=按下
```

- Omega.7 内部是**一个物理设备**但通过**两个逻辑端点**通信（平移 + 夹持/旋转）
- `dhd.open()` 默认只打开平移端点，可能附带打开夹持端点，也可能不打开
- 你测试中 `ret=0` 说明 API 调用成功，但一直返回 `-0.794°`（接近 0° 的无效值）

### 第 2 段：Franka 连接

```python
panda = panda_py.Panda("192.168.1.51")     # TCP 连接
gripper = panda_py.libfranka.Gripper(ip)    # 夹爪独立连接
gripper.homing()                            # 必需！让夹爪标定行程范围
```

- 机械臂和夹爪通过同一条网线但不同端口通信
- `homing()` 必须执行，否则 `move()` 和 `grasp()` 可能不工作

### 第 3 段：位置映射

```python
delta = raw_pos - omega_home            # Omega 相对于零点的位移
target_pos = virtual_ref + delta * 3.0 * SIGN  # 映射到 Franka
ctrl.set_control(target_pos, init_ori)
```

**公式**：`Franka末端位置 = 初始位置 + (Omega当前位置 - Omega零点) × 3.0 × 坐标方向`

- `SCALE_POS = 3.0`：Omega 直径 ~0.2m 的球空间被映射到 Franka 约 0.6m 范围
- `SIGN = [-1, -1, 1]`：Omega 和 Franka 的坐标轴定义不同，需要翻转

### 第 4 段：夹爪映射

```python
dhd.getGripperAngleDeg(angle)
omega_grip = angle.value
grip_norm = clip((angle - 0) / (-60 - 0), 0, 1)  # 张开→1，捏合→0
target_width = grip_norm * 0.08                   # 映射到 Franka 开度
```

| Omega 夹爪状态 | 预期角度 | grip_norm | Franka 夹爪开度 |
|---------------|---------|-----------|----------------|
| 完全张开 | ~-60° | 1.0 | 0.08m (全开) |
| 半开状态 | ~-30° | ~0.5 | ~0.04m |
| 完全捏合 | ~0° | 0.0 | 0m (闭合) |

## 四、可能的原因（按检查顺序排列）

### 原因 1：Omega.7 需要标定（⬅️ 最可能）

从你文档中看到：
> **"设备每次开机都需要校准一次"**
> - 位置校准：用校准杆放在底座校准孔中
> - **姿态校准：必须手动将手腕旋转轴和夹爪移动到各自的行程终点**

如果你没有做过校准，Omega 的位置数据可能是对的（平移设备自动校准），但**夹爪角度传感器没有完成行程终点检测，一直返回固定值**。

**解决方案**：
1. 用校准杆插在底座孔中完成**位置校准**
2. **手动将夹爪捏合到底（捏到最紧）再松开到底（完全张开）**，让设备检测行程终点，校准夹爪角度
3. 观察状态灯：**快速闪烁**=需要校准，**常亮**=就绪

### 原因 2：平移+夹持是两个独立设备，openID 未正确处理

虽然你的 `getDeviceCount()` 我没看到确切输出，但即使只有 1 个设备，也可能需要特殊方式打开夹持功能。需要验证：

### 原因 3：夹爪角度范围是正值而非负值

用户文档说：
> **"若是右手操作涉及的 omega.7 设备，返回一个正角度"**

如果你们的 Omega.7 是右手版本，角度范围可能是 0°（张开）~ 30°（捏合）的正值，而非我假设的 `-60° ~ 0°` 负值。
