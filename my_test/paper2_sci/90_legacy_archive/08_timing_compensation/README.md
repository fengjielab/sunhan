# 08 阻抗时序与操作者作用分析

## 一句话结论

现有 180 次数据支持“**接触前视觉前馈优于接触后反应式力适应**”，不支持“视觉与力反馈产生额外协同增益”；操作者补偿目前是可检验假设，需要匹配机器人回放才能作因果判断。

## 为什么改变主线

原“先验可信度纠错”鼠标先导只有 C0/C1/W0/W1 各 1 次，且在当前可读取的第二轮数据中：C1−C0 主力冲量约 −0.043 N·s，W1−W0 约 +0.021 N·s。修正器虽然改变了刚度和 trust 状态，但没有形成错误先验下稳定改善的结果。因此不再追加正式 80 次信任实验。

这不是把负结果隐藏，而是把它作为机制否证：**状态变量发生变化，不等于任务表现获得改善。**

## 当前可写创新

1. 将四模式重构为“视觉前馈 × 反应式力适应”的严格配对 2×2 因子实验。
2. 用接触事件对齐，将干预分为接触前、初始接触 0–0.2 s、自适应 0.2–1.0 s，比较“何时介入”而不仅比较全程均值。
3. 同时提取 Omega 输入、目标轨迹、机器人运动和跟踪误差，显式把操作者行为作为人机系统中的竞争通道。
4. 对力驱动刚度策略作内生性审计：自适应模式中的刚度是力的结果，不能用刚度—力相关冒充因果效应。
5. 提出匹配人机—机器人回放分解，以固定运动学条件估计直接机械效应，再由总效应与直接效应之差估计操作者介导成分。

## 文件

- `analyze_timing_compensation.py`：唯一分析入口。
- `human_motion_trial_metrics_180.csv`：180 试次的操作者/目标/机器人运动派生指标及源 CSV 路径。
- `paired_timing_contrasts.csv`：45 个配对块的预定义对比、效应量、CI 和 Holm 校正。
- `mode_descriptives_timing.csv`：四模式描述统计。
- `adaptive_endogeneity_audit.csv`：刚度—力相关及因果警告。
- `mouse_pilot_falsification.csv`：四条鼠标先导、源路径和 SHA-256；只作否证性先导。
- `new_direction_summary.json`：机器可读摘要。
- `analysis_plan.md`：现有数据与新增验证的统计边界。
- `matched_replay_protocol.md`：最小必要补实验。
- `decision_log.md`：方向变更记录。

## 重要限制

- 参与者只有 5 人；45 个配对块不能替代参与者层面的样本量。
- 180/180 成功使成功率没有区分度。
- 当前运动指标能说明人类输入随条件变化，但不能单独证明这种变化是“补偿”。
- 鼠标先导由人为施加的正确/过硬先验构成，并非自然视觉误识别，不可写成“系统纠正了真实识别错误”。
- 控制周期仍有约 2% 的 >50 ms 长尾；回放实验必须同步记录并报告。

## 下一步门槛

匹配回放结果若表明：固定目标轨迹后策略差异明显小于人类在环总差异，才能把“操作者介导/补偿”升级为主要机制结论。若两者接近，则论文应定位为“阻抗干预时序的机械效应”，不强调人因机制。
