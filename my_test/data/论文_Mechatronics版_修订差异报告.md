# Mechatronics 稿件校准式大修差异报告

## 1. 版本与修订原则

- 原稿：`论文_Mechatronics版_最终术语与图文一致性检查稿.md`，未覆盖、未写入。
- 修订稿：`论文_Mechatronics版_编辑修订稿.md`。
- 图表输出：`../drawing/revision_submission/`，Fig. 2–7 均提供 PNG、PDF 和 SVG。
- 本轮采用“校准而非降级”：保留四项贡献、七维参数设计、五模式实验、C–E 核心系统消融和操作者/对象分层结果；只限制超出当前证据范围的实时性、机制因果性和人群泛化表述。

按“一个可独立判断的主张或编辑动作”为计数单位，第一轮记录 43 项实质性处理；作者确认正式实现、实验时序、视觉数据和图源后，第二轮新增 18 项事实解锁处理；第三轮完成 11 项专业化叙事升级；本轮依据专业评议再完成 12 项统计与可复现性校准，其中 **增强 5 项、合并 1 项、限定 5 项、删除 1 项**。此外修复数字/表图一致性 11 处，更新或重生图表 6 幅。这里的计数用于追踪编辑决策，不等同于 Git 增删行数。

### 第二轮事实解锁摘要

- 正式实验实现以当前 `interactive_teleop.py` 为依据：424×240彩色流、15 fps、帧队列1、结果队列2、置信度阈值0.25、逐轴死区、Z向提示及约300 ms平滑过渡。
- 实验流程不等待视觉识别：任务开始后相机与遥操作同步启动，首次有效结果在接近阶段触发一次性策略选择；不保证早于物理接触。
- 成功与失败试验均计时至统一任务终点。
- 180张测试照片为每类30张独立拍摄照片，独立于训练和参数调节数据。
- 三名参与者均在实验前签署书面知情同意；Fig. 1–3原始图未使用生成式AI。
- 因此论文主线由“接触前调度”改为“接近阶段一次性调度”；剩余实质性投稿阻断项为机构伦理判断。

### 第三轮专业化叙事升级摘要

- 标题由流程导向的“接近阶段多通道参数调度”提升为“视觉语义驱动跨通道机电参数协同调度”；接近阶段仍作为真实触发时序保留在摘要、方法和图注中。
- 将15 fps彩色采集、48.19 ms平均单帧推理和名义200 Hz监督式遥操作更新组织为“多速率异步机电架构”，不再把三个不同概念压缩成不准确的“约20 Hz视觉”。
- 恢复D435i作为RGB-D设备的完整硬件名称，同时明确正式实验采用color-only配置、深度流未参与语义识别或参数调度。
- 将队列长度1/2、非阻塞读取和约300 ms smoothstep从配置罗列提升为“限制积压的单槽帧通信、事件同步和跨通道协调激活”的工程设计链。
- 删除图内重复的答辩式否定语句，Fig. 2突出多速率数据流和七维参数协调，Fig. 3突出五模式消融与跨通道参数空间；必要边界仅在caption、方法和局限性各承担一次明确功能。

## 5. 主张弱化的必要性与保留的工程意义

1. **“硬实时”改为“关键路径之外、名义 200 Hz”。** 必要性：周期数据有长尾且无 RTOS 证明。保留意义：异步视觉不作为每次遥操作更新的同步依赖，仍是可部署的架构贡献。
2. **“停顿导致时间收益”改为“与停顿减少方向相容”。** 必要性：无阶段级标注，且两模式停顿中位数均为 3。保留意义：1.79 s 的主要终点优势和探索性过程方向仍完整呈现。
3. **“多通道各自贡献”改为“完整参数包的系统级贡献”。** 必要性：C–E 同时增加触觉接口和夹爪执行通道，不能拆分单通道因果。保留意义：完整参数包相对仅阻抗调度的系统级收益正是论文核心工程问题。
4. **“普遍适应性”改为“当前三名操作者和六对象内一致”。** 必要性：参与者仅 3 名。保留意义：三名操作者和六类对象均呈同方向的分层结果仍是有价值的重复测量证据。
5. **“视觉测试100%泛化”改为“独立受控测试集180/180”。** 必要性：虽然180张照片独立拍摄且未参与训练或调参，但对象实例、背景与光照仍受控。保留意义：视觉模块在当前独立受控条件下的触发可靠性得到逐图数据支持。
