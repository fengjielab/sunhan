# Submission-required information that must not be inferred

## Blocking human-participant information

- [ ] Name of the approving ethics committee or confirmation of a documented exemption.
- [ ] Approval/exemption identifier and date, where applicable.
- [ ] Informed-consent procedure and whether consent covered use/publication of the archived data.

The manuscript must not be submitted until these items are confirmed from contemporaneous institutional records. They cannot be replaced by a limitation statement.

## Required title-page and declaration information

- [ ] Final author list, order, affiliations, corresponding author, and contact details.
- [ ] Author contributions.
- [ ] Funding sources and grant numbers, or an explicit no-funding declaration.
- [ ] Conflicts/competing interests declaration.
- [ ] Acknowledgements.
- [ ] Data-availability statement with repository URL/DOI and any human-data access restrictions.
- [ ] Code-availability statement with versioned repository URL/DOI and license.

## Metadata to recover if possible; otherwise disclose as limitations

- [ ] Participant age, sex/gender, handedness, prior teleoperation experience, recruitment, compensation, and training.
- [ ] Participant instructions, practice, rest schedule, object geometry, physical-instance identity, start/destination placement, and tolerances.
- [ ] Computer, operating system, hardware, acquisition-library versions, and whether an unlogged external force/torque sensor was physically present.
- [ ] Prospective randomization/counterbalancing schedule.
- [ ] Contemporaneous technical documentation for the six superseded acquisitions.

## Journal-dependent checks

- [ ] Select target journal and apply its word, figure, table, reference, declaration, and supplementary limits.
- [ ] Determine whether highlights, a graphical abstract, reporting checklist, or separate title page are required.
- [ ] Convert author-date citations and references to the selected journal style only after journal selection.
