# THMS English Translation Audit

本文件仅记录需要作者人工确认的实质性问题，不记录常规语法或风格修改。

## 1. 主要结局的英文名称是否应统一

- **中文位置：** 4.4 节使用“操作性阈值以上力冲量”，摘要、5.3 节和图4使用“操作性超额力冲量”。
- **当前英文：** 前者译为 *operational above-threshold force impulse*，后者译为 *operational excess-force impulse*。
- **请作者确认：** 两个中文名称是否指同一个冻结结局变量。如果是，投稿稿宜统一为一个英文名称；如果不是，需要在 Methods 中明确两者的计算关系，以避免读者误认为结局定义发生变化。

## 2. “重复区组”的实验设计术语

- **中文位置：** 4.1 节“3个重复区组”。
- **当前英文：** *3 repeated blocks*。
- **请作者确认：** 原始设计中的正式术语是 *repeated blocks*、*replicate blocks*，还是其他预先定义的区组名称。该选择不改变数字或分析，但会影响英文对实验结构的准确描述。

## 3. 摘要进行了整体信息顺序重构

- **当前处理：** 英文摘要按 problem → framework → archived system → G/F/E findings → changed comparison identity → bounded E–A exploratory result → methodological implication 的顺序重构，没有增加实验事实、机制解释或因果主张。
- **请作者确认：** 该顺序符合当前投稿叙事重点，尤其是以 realized intervention、delivery/exposure 和 scientifically supportable comparison 为主线，而不以 12 个受控案例为摘要中心。
