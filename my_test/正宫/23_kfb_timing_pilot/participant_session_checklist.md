# 阶段B志愿者会话清单

## 开始前

- [ ] 阶段A验收报告 `overall_pass=true`，此后采集代码和参数未改变。
- [ ] 伦理审批/豁免、知情同意和数据撤回流程有效。
- [ ] 参与者编号与运行表一致，不记录姓名到机器人数据文件。
- [ ] 固定垫、起始位姿、急停和数据目录检查通过。
- [ ] 向参与者说明反馈可能变化，但不说明条件身份或方向假设。

## 执行

- [ ] 先完成5次训练；训练文件标记 `analyzed=0`。
- [ ] 完成3个正式区组，每组5次且每个匿名条件一次。
- [ ] 第1、2区组后休息2–3分钟。
- [ ] 仅按冻结运行表顺序执行，不现场调换条件。
- [ ] 技术失败保留原文件；不因力值、运动量或结果方向补测。
- [ ] 任何不适、异常振动或安全担忧立即急停并终止会话。

## 会话结束

- [ ] 20个预定试次均有明确的 complete/incomplete 状态。
- [ ] 没有重复trial ID或被覆盖的文件。
- [ ] 技术失败和补测关系已记录，但未查看条件结局差异。
- [ ] 参与者已完成退出说明并获得研究联系人信息。
