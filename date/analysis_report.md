## 4. 主要结论

1. **完成时间方面，全自动模式在三类物体上均为最优。**  
   soft、medium、hard 的全自动完成时间分别为 18.26 s、18.07 s、16.49 s，均低于固定增益、选择模式和消融组。

2. **hard 和 medium 物体上，全自动模式的路径长度也明显更短。**  
   medium 全自动相对消融路径减少 27.6%，hard 全自动相对固定增益减少 10.0%、相对选择模式减少 12.1%。

3. **soft 物体上，全自动模式虽然最快，但路径长度不是最优。**  
   soft 的选择模式路径最短，为 0.5712 m；全自动为 0.7079 m。说明软物体场景下，全自动策略可能让操作者更快完成，但运动路径更积极或存在少量轨迹尖峰。

4. **全自动 soft/medium 轨迹中存在明显最大速度尖峰。**  
   soft 全自动最大速度 1.9114 m/s，medium 全自动最大速度 1.4226 m/s，明显高于其他模式约 0.10-0.16 m/s 的范围。  
   结合之前 vision 模式 Omega7 读取问题，这些尖峰更可能来自 USB 读取瞬时异常或位置跳变，而不一定代表真实操作速度。

5. **参数切换符合软/中/硬策略逻辑。**  
   soft 全自动最终参数为低刚度低反馈：`K_trans=50, K_fb=0.2`；medium 为中等参数：`K_trans=150, K_fb=0.5`；hard 为较高阻抗/反馈：`K_trans=200, K_fb=0.7`。

## 5. 论文可用表述

可以写：

> 实验结果表明，视觉语义驱动的全自动多参数阻抗辅助模式在三类物体上均取得最短任务完成时间。相较固定增益模式，全自动模式在 soft、medium、hard 三类物体上的完成时间分别降低 7.7%、10.8% 和 25.0%；在 medium 与 hard 物体上，主端运动路径分别降低 16.0% 和 10.0%。说明视觉语义信息参与多参数阻抗调度后，能够提高遥操作任务效率，尤其在中硬物体抓取任务中表现更明显。

对于 soft 物体建议谨慎表述：

> 在 soft 物体实验中，全自动模式完成时间最短，但路径长度高于人工选择模式，表明低刚度视觉策略能够提升完成速度，但软物体任务仍受操作者路径规划和主端输入稳定性影响。

## 6. 后续建议

- 若要写成功率和 NASA-TLX，需要补充人工评分表；当前 JSON 中没有这些字段。
- 建议对全自动 soft/medium 轨迹进行速度尖峰过滤，或用 P95/P99 速度替代最大速度作为稳定性指标。
- 如果论文中要强调“视觉显示消融”，当前“消融”JSON 显示 `vision_enabled=false`，更适合表述为“固定参数消融/无自适应消融”。若要严格对应 Mode D“仅视觉显示不调参”，建议补采一次 D 组。
