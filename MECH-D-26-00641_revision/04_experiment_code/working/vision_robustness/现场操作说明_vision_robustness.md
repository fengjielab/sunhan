# 视觉鲁棒性实验：现场操作说明

本实验只采集 RealSense 彩色视频并运行 YOLO，不连接、不控制机械臂。总共 120 轮，每轮录像 10 秒。

## 一、实验前准备

### 1. 物品

准备以下物品，并在整个实验期间尽量使用同一批物品：

- 香蕉 A、瓶子 A、剪刀 A：原实验中使用的物品；
- 香蕉 B、瓶子 B、剪刀 B：与 A 同一语义类别、但外观不同的物品；
- 未知物体：订书机、螺丝刀、卷尺、小纸盒、海绵；
- 杂物：钥匙、胶带卷、直尺；
- 不反光的灰色或黑色遮挡卡；
- 可移动台灯；
- 胶带。

### 2. 桌面和相机

1. 把 RealSense 相机固定在与论文人机实验相同的位置和角度。
2. 相机固定后，整个实验期间不要移动相机。
3. 用胶带在桌面标记一个 `15 cm × 15 cm` 的中央目标区。
4. 在中央目标区内再标出 5 个位置：

   - `R01`：中心；
   - `R02`：中心左侧 3 cm；
   - `R03`：中心右侧 3 cm；
   - `R04`：中心向相机方向 3 cm；
   - `R05`：中心远离相机方向 3 cm。

5. 关闭机械臂，或让机械臂保持静止，不要让机械臂进入画面。
6. 相机、桌面目标区和拍摄背景准备好后，不要再改变它们的位置。

## 二、启动命令

以下命令在 Ubuntu 实验电脑上运行。先确认已经把整个 `vision_robustness` 文件夹复制到电脑上。

### 1. 进入代码目录

```bash
cd /home/mfj/sunhan/vision_robustness
```

如果你的实际目录不同，只需要修改这一行。

### 2. 设置模型和输出目录

```bash
MODEL=/home/mfj/sunhan/yolo/ultralytics-8.3.163/yolo11n.pt
OUT=/home/mfj/sunhan/vision_robustness_data
```

### 3. 检查 Python 依赖

```bash
python3 -c "import cv2, pyrealsense2, ultralytics; print('依赖正常')"
```

如果这行报错，先不要开始正式采集，需要先安装或加载实验电脑上原有的运行环境。

### 4. 生成任务表

```bash
python3 offline_vision_capture.py --make-manifest-only
```

该命令会生成或检查 `scene_manifest.csv`。总任务数是 120 轮：

- `normal`：15 轮；
- `dim`：15 轮；
- `backlight`：15 轮；
- `occlusion50`：15 轮；
- `clutter`：15 轮；
- `multiobject`：15 轮；
- `new_instance`：15 轮；
- `unknown`：15 轮。

## 三、每一轮的固定操作流程

每个条件都按照下面的流程执行。不要根据识别结果决定是否重做；识别错误、没有检测到物体、置信度低，都是实验结果。

1. 看终端显示的 `Episode`、物体名称和摆放说明。
2. 按终端说明摆放物体。
3. 确认相机、灯、物体和人的手都没有继续移动。
4. 等待约 2 秒，让相机自动曝光稳定。
5. 在视频窗口中按 `SPACE` 开始录像。
6. 录像自动持续 10 秒，期间不要移动物体、相机、灯或手。
7. 录像结束后，终端会显示识别结果。
8. 如果这一轮摆放完全正确，输入 `Y` 并回车保存。
9. 如果摆放错误、有人手进入画面、灯或物体意外移动，输入 `R` 并回车重做。
10. 如果需要暂停实验，输入 `Q` 并回车退出；已经按 `Y` 保存的轮次不会丢失。
11. 下一轮开始前，把上一轮的物体全部拿出画面，再按新的 Episode 说明重新摆放。

### 键盘按键

| 按键 | 作用 |
|---|---|
| `SPACE` | 开始当前轮 10 秒录像 |
| `Y` | 接受并保存当前轮 |
| `R` | 当前轮重做，不保存本次录像 |
| `Q` | 退出，之后可以继续未完成任务 |
| `X` 或 `ESC` | 录像过程中取消当前轮 |

## 四、最重要的摆放规则

### R01–R05 是位置，不是五个不同物体

例如终端显示：

```text
Episode ...: ..._BANANA_R03
Put banana ... 3 cm RIGHT of center ...
```

这表示：

1. 拿香蕉 A；
2. 放在中央目标区右侧 3 cm 的 `R03` 点；
3. 保持原实验中的标准朝向；
4. 按 `SPACE` 录像 10 秒；
5. 结束后按 `Y` 保存；
6. 下一轮按照下一条终端指令移动或更换物体。

五个重复位置使用同一个物体 A 即可，不需要每个位置换一根香蕉。除 `new_instance` 条件外，不要随意更换成 B 物体。

### 任务顺序是随机的

程序会随机打乱每个条件中的任务。因此不能假设第一轮一定是香蕉，也不能假设 R01、R02、R03 按顺序出现。每一轮都以终端显示的 `Episode` 和英文摆放说明为准。

## 五、八种实验条件具体怎么摆

### 1. `normal`：正常光照

启动命令：

```bash
python3 offline_vision_capture.py --model "$MODEL" --output "$OUT" --condition normal
```

每一轮只放终端指定的一个目标物：香蕉 A、瓶子 A 或剪刀 A。根据 `R01–R05` 放在指定位置，使用正常实验室光照，画面中不要出现其他物体。

例如：

- 香蕉 R01：香蕉放中心；
- 香蕉 R02：香蕉放中心左侧 3 cm；
- 香蕉 R03：香蕉放中心右侧 3 cm；
- 香蕉 R04：香蕉放中心靠近相机 3 cm；
- 香蕉 R05：香蕉放中心远离相机 3 cm。

瓶子和剪刀完全按照同样的规则操作。

### 2. `dim`：弱光

启动命令：

```bash
python3 offline_vision_capture.py --model "$MODEL" --output "$OUT" --condition dim
```

1. 目标物体仍然放在终端指定的 `R01–R05` 位置。
2. 不要改变物体朝向。
3. 关闭主灯或降低照明，使目标物表面大约为 `50–100 lux`。
4. 每一轮都保持相同的弱光设置。
5. 不要在录像过程中继续调灯。

没有照度计时可以使用同一部手机的照度计应用估计。论文中应表述为近似照度。

### 3. `backlight`：背光

启动命令：

```bash
python3 offline_vision_capture.py --model "$MODEL" --output "$OUT" --condition backlight
```

1. 目标物体仍然放在终端指定的位置。
2. 把台灯放在物体后方约 `30–50 cm`。
3. 台灯大致朝向相机，让物体形成明显背光。
4. 台灯和灯架不能遮挡目标物体。
5. 每一轮保持台灯位置不变。

### 4. `occlusion50`：约 50% 遮挡

启动命令：

```bash
python3 offline_vision_capture.py --model "$MODEL" --output "$OUT" --condition occlusion50
```

1. 目标物体仍然放在终端指定的 `R01–R05` 位置。
2. 使用不反光的灰色或黑色遮挡卡。
3. 遮住目标可见轮廓的大约一半。
4. 奇数重复 `R01、R03、R05`：从目标左侧遮挡。
5. 偶数重复 `R02、R04`：从目标右侧遮挡。
6. 遮挡卡不能在录像过程中移动。

### 5. `clutter`：固定杂物

启动命令：

```bash
python3 offline_vision_capture.py --model "$MODEL" --output "$OUT" --condition clutter
```

每一轮放置：

- 终端指定的目标物放在中央目标区内；
- 钥匙放在目标左侧；
- 胶带卷放在目标右侧；
- 直尺放在目标后方。

三个杂物放在目标区外，不要遮挡目标。120 轮中使用同一组三件杂物，并尽量保持它们的相对位置不变。

### 6. `multiobject`：两个已知物体

启动命令：

```bash
python3 offline_vision_capture.py --model "$MODEL" --output "$OUT" --condition multiobject
```

每一轮放两个物体：

| 目标物 | 旁边的物体 |
|---|---|
| 香蕉 | 瓶子 |
| 瓶子 | 剪刀 |
| 剪刀 | 香蕉 |

操作规则：

1. 目标物放在中央目标区内的指定 `R01–R05` 位置。
2. 另一个物体放在目标左侧或右侧 `12–15 cm`。
3. 两个物体的深度保持一致。
4. 奇数重复 `R01、R03、R05`：旁边物体放左侧。
5. 偶数重复 `R02、R04`：旁边物体放右侧。
6. 两个物体都不能在录像过程中移动。

### 7. `new_instance`：同类别的新实物

启动命令：

```bash
python3 offline_vision_capture.py --model "$MODEL" --output "$OUT" --condition new_instance
```

每一轮只放一个目标物，但必须使用同一类别的 B 物体：

- 香蕉目标：使用香蕉 B；
- 瓶子目标：使用瓶子 B；
- 剪刀目标：使用剪刀 B。

香蕉 B 仍然必须是真香蕉，不能用苹果替代；瓶子 B 和剪刀 B 也必须保持语义类别不变。位置和姿态按照终端显示的 `R01–R05` 执行。

### 8. `unknown`：未知物体

启动命令：

```bash
python3 offline_vision_capture.py --model "$MODEL" --output "$OUT" --condition unknown
```

每一轮只放终端指定的一个未知物体：订书机、螺丝刀、卷尺、小纸盒或海绵。未知物体只做 `R01–R03` 三个位置：中心、左侧 3 cm、右侧 3 cm。

如果模型把未知物体错误识别成香蕉、瓶子或剪刀，这也是有效结果，不能因为识别错误而重做。

## 六、推荐的实际执行顺序

不要一次把所有命令连续粘贴执行，因为每个条件都需要重新布置现场。

### 第一天：先做正常光照 15 轮

```bash
python3 offline_vision_capture.py --model "$MODEL" --output "$OUT" --condition normal
```

正常组完成后，检查输出目录：

```bash
ls -lh "$OUT"
```

查看已完成轮数：

```bash
python3 -c "import csv; p='$OUT/episode_summary.csv'; print('已保存轮数:', sum(1 for _ in open(p, encoding='utf-8-sig'))-1)"
```

确认视频、检测结果和编号都正常后，再做下面的条件。每做完一个条件，都可以用同一条统计命令检查总保存轮数。

## 八、什么时候可以重做

只有以下情况可以输入 `R` 重做：

- 放错目标物或干扰物；
- R01–R05 位置明显放错；
- 遮挡比例明显错误；
- 录像时有人手进入画面；
- 相机、灯或物体意外移动；
- 程序、相机或视频写入报错。

以下情况不能重做：

- 没有检测到物体；
- 置信度低；
- 识别成错误类别；
- 未知物体被识别成已知类别。

## 九、常见情况

### 中途按 Q 退出怎么办？

直接重新运行当前条件的同一条命令即可。程序会读取 `episode_summary.csv`，跳过已经按 `Y` 保存的轮次，继续下一个未完成轮次。

### 这一组已经做完怎么办？

把现场改成下一个条件，再运行对应的 `--condition` 命令。不要删除输出目录，也不要删除 `episode_summary.csv`。

### 命令显示 MODEL HASH MISMATCH 怎么办？

停止采集，确认 `MODEL` 指向论文锁定的模型文件。不要直接添加 `--allow-model-mismatch`，除非已经确认更换模型并获得实验负责人同意。
